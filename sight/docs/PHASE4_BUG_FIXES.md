# Phase 4 bug-fix report

Repairs were made in a separate Phase-4 build. Earlier phases and the original UI are preservation inputs. Tests use disposable files and synthetic prompts.

| ID | Reproduction / root cause | Repair | Regression evidence |
| --- | --- | --- | --- |
| P4-01 | A hard-linked `browser-token` caused startup to truncate an unrelated owner file. | Validate links/ancestors; create a private temporary file and atomically replace the token. | `test_launch_token_hardlink_does_not_truncate_other_file`; failing [before XML](../../evidence/hardening_before.xml). |
| P4-02 | Core and learning SQLite migrations followed hard links; journal/WAL/SHM siblings and junction ancestors were not consistently checked. | Check database and sidecars before every connection; reject symlink/junction ancestors before resolution; preserve corrupt databases. | `test_database_hardlink_rejected_before_migration`, `test_sqlite_sidecar_hardlinks_rejected`, Windows junction and corruption cases. |
| P4-03 | Legacy backup checksum writes could follow a hard link. | Validate the checksum path before making the backup and write the sidecar atomically. | Both Store and BrainStore covered by `test_legacy_backup_checksum_link_cannot_overwrite_owner_file`. |

| P4-05 | Local Ollama JSON endpoints accumulated an unbounded response before parsing. | Stream raw response bytes with a 1 MiB cap; reject compression; bound metadata/unload calls; handle malformed data. | Tags/show/chat oversized-stream tests stop reading at the bound. |

| P4-20 | Memory compaction committed its content, FTS row and audit event before its provenance edges. | P4-21 | FTS applied its result limit before expiry, ancestry and remote-privacy filtering. | P4-22 | Every derived-source lookup opened another connection and used Python recursion. | P4-23 | Following the owner's switch to normal Gemma, the direct helper still selected the uncensored alias and the backend applied its derivative-specific sampling to the official tag. | Select `gemma4:e4b-it-qat` in the saved configuration/direct helper/live smoke script; apply official sampling to that exact tag while retaining legacy profile behavior. | Three failing selection/sampling cases in [before XML](../../evidence/official_model_before.xml); four passing cases in [after XML](../../evidence/official_model_after.xml). Official file hashes are verified; live inference remains unverified because Ollama is absent. |

The initial hardening reproduction produced **9 failures and 2 passes**. Subsequent changes added further regressions. The complete current results are in [test results](PHASE4_TEST_RESULTS.md); do not substitute the initial subset for the final suite.

Static link checks reduce accidental and malicious redirection through existing links. They are not a complete same-owner, concurrent filesystem-race boundary. A user who can modify the application, runtime or both manifest and data is outside the protection offered by these checksum checks.

Unresolved: uncensored model reasoning reliability; complete external binary vulnerability coverage; fresh Windows account qualification; broad integrations and complete source semantic review. These are explicit readiness gaps, not repaired bugs.
